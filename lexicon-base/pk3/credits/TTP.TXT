-=[ INSTALLATION ]=-
-------------------------------------------------------------------------------
Before installing make sure you have a clean copy of DooM II installed and that
there are no DooM I files in the same directory.

To install run TTP.BAT, to uninstall just do the same, TTP will recognize 
wether it is installed or not :)
(You have to uninstall TTP before playing normal DooM II again.)

NOTE TO DEHACKED USERS: any existing DOOMHACK.EXE will be deleted, if you are
working on a patch save it to a file first!


-=[ RUNNING TTP ]=-
-----------------------------------------------------------------------------
Before running TTP make sure it is installed properly. For a single player 
launch you can use TTPSTART - when running a network game every player has to
have TTP installed and have TTP.WAD added when starting.


-=[ BONUS LEVELS ]=-
