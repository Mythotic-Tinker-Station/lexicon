* Version Notes *

	0.x	Beta test versions
        1.0     Our first public release
        1.1     Bug fix release
        1.2     Latest update

New for v1.1

 Recompiled TALOSL.WAD using BSP v2.1 -
   Doing this corrected the bug in MAP15 which left the Mancubus
stuck INSIDE its platform instead of standing on top of it.  This
was not a design error - just a BSP error...
   Recompiling the WAD also fixed all the texture bleed problems
(notably in MAPs 04 and 15)...  Again, another old BSP problem...
   As a side effect, it also made the WAD about 100k smaller than
the previous version...

 Credits corrected -
   I'd mistakenly credited Malcolm Sailor with recording one of the
demos used in the game.  In fact it was Patrick Martin...  Sorry
about that Patrick :-)

New for v1.2

 Fixed some minor bugs in level 11

 Added level title graphics for all 20 levels

 Changed version number in end screen!
