version 1.0 to 1.1
1. Two bugs removed from map 1. (linedef -> lightlevel to 0 everywhere)
                                (the PLASMA and BFG9000 behind the bars)
2. Some pictures changed.

version 1.1 to 1.2
1. There are three new maps. (map 11-13)!!
2. One bug removed from map 2. (deathmatch spot in closed room)
3. One bug removed from map 7. (deathmatch exit when playing nomonsters)
4. Some textures and pictures changed.

version 1.2 to 1.2a
We've decided to denote bugfixes with letters instead of a new number.
1. Some changes made on map 4.
2. Texture changed on map 10.
3. Some (important) changes made on map 12.
4. One useless vertex removed from map 13.

version 1.2a to 2.0
1. Allmost all the maps have been partly or greatly changed.
2. Seven new maps. (map 14-18)
3. Some new textures and pictures.
4. Two new demos.
5. New fist sound patch.
6. All map names have been changed to the names we gave 'em. (OK except when
   U press tab, but that name is in the DOOM2.EXE, and we don't mess with 
   that!)

version 2.0 to 2.4
1. Four new maps. (map 19-22)
2. Some new graphics.
3. New music.
4. New floor(!) textures.
5. Maps 3, 12 and 13 underwent some changes.

version 2.4 to 2.4a
1. New e-mail address.

(LMP-files from an older version of THE ABYSS probably won't work with a
